HUMAN EYE MCQ TEST

Student files:
- index.html
- style.css
- script.js

Teacher demo:
- admin.html

FEATURES
- 13 questions
- One question at a time
- Previous and Next buttons
- Question 13 shows Submit instead of Next
- Selected answer remains selected when navigating back
- No correct/incorrect feedback is shown
- 30-minute timer
- Student name and roll number
- "Under the guidance of Bishal Sir" shown after entering details / on start screen
- Student marks are not displayed

IMPORTANT
This version uses localStorage only as a demonstration.
For a real online test, localStorage must be replaced with Firebase (or another backend), otherwise results are not collected centrally.

GITHUB PAGES
Upload index.html, style.css and script.js to the repository root.
Then GitHub -> Settings -> Pages -> Deploy from branch -> main -> /root.


UPDATED VERSION
- Test duration is 10 minutes.
- The Test Submitted screen is now a separate submitted.html page.
- After submission (or when time runs out), the student is redirected to submitted.html.
- The Previous/Next bottom navigation exists only on the test page and is not shown on the submission page.
